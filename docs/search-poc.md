## 1. 모델 설정 요약

| 항목 | 값 |
| --- | --- |
| 모델 | `gemini-embedding-2` |
| 차원 | 768 (권장값 768·1536·3072 중 최소) |
| 거리 | cosine. 모델이 정규화하므로 별도 처리 없음 |
| 입력 | 검색 `task: search result \| query: {질문}` / 저장 `title: {도메인} \| text: {질문}` |
| 호출 | QA 1건씩. 호출 전체 제한시간 10초, SDK 자체 재시도 끔 |
| S3 Vectors 인덱스 | `clf-qa-vectors-dev` / `qa-index-gemini-v1` (768, float32, cosine) |

**선정 이유**: 최신 모델, 한국어 지원, 자동 정규화, 입력 8,192 토큰, 768차원은 저장·검색 비용과 속도가 가장 유리합니다.

**Bedrock에서 바꾼 이유**: 새 AWS 계정이라 Bedrock 모델 호출 한도가 모두 0이었고, Support 케이스 처리를 기다릴 수 없었습니다.

**1536차원으로 올리는 기준**: 3번 평가에서 Recall@3이 목표에 못 미치면 1536으로 다시 평가합니다. 차원을 바꾸면 새 인덱스를 만들고 전체를 재임베딩합니다 (indexing.md 8절).

CloudShell(ap-northeast-2)에서 `python3 scripts/s3v_gemini_poc.py` 실행. 키는 Secrets Manager `clfqa/dev/gemini-api-key`에서 읽음.

| 확인 항목 | 결과 |
| --- | --- |
| 출력 차원 | 768 |
| 정규화 | 길이 1.0000 (모델이 처리, 별도 정규화 불필요 확인) |
| 비슷한 질문 1위 (메모리 cosine, 4문항) | 4/4 정답 |

| 같은 사용자의 다른 CLF 주제 QA | 0.57 ~ 0.67 |

| domain 필터 | SECURITY 지정 시 해당 QA만 |

| 없는 key 삭제 | 오류 없이 성공 |
| 정리 | PoC 벡터(`poc-*`) 모두 삭제 |

**관찰**
- 관계없는 질문(0.48)과 정답(0.76 이상)은 잘 갈립니다.
- 하지만 **같은 CLF 안의 다른 주제도 0.57~0.67**로 꽤 높습니다. 최소 유사도로는 "AWS와 상관없는 질문"을 거를 수 있지만, "다른 AWS 주제"까지 거르기는 어렵습니다. 순위로 구분해야 합니다.
- 샘플 4문항 기준 최소 유사도 후보는 0.5~0.55 정도입니다. 3번 평가 질문셋(36문항)으로 다시 정합니다.

Java 경로의 실호출 확인은 로컬에 키가 있을 때 아래로 합니다.

```sh
GEMINI_API_KEY=... ./gradlew test --rerun --tests '*GeminiEmbeddingLiveTest'
```

## 3. 검색 평가

### 3-1. 질문셋 (원본은 노션)

| 구분 | 개수 | 내용 |
| --- | --- | --- |
| 원본 질문 | 12 | CLF 4개 영역 × 3. 저장된 QA 역할 (`embedDocument`) |
| 변형 질문 | 24 | 원본마다 2개. 같은 뜻을 다르게 물음. 검색어 역할 (`embedQuery`) |
| 관계없는 질문 | 3 | 저장된 QA와 관계없는 질문. 임계값 결정용 |

질문셋 파일 형식은 [search-eval-template.json](search-eval-template.json)을 따릅니다. 노션 질문셋을 이 형식으로 옮겨 쓰면 됩니다.

### 3-2. 지표와 목표

| 지표 | 계산 | 목표(제안) |
| --- | --- | --- |
| Recall@1 | 변형 질문으로 검색했을 때 1위가 원본인 비율 | 0.75 이상 |
| Recall@3 | 원본이 3위 안에 드는 비율 | 0.90 이상 |
| 관계없는 질문 최고 유사도 | 관계없는 질문과 원본 12개 사이 유사도의 최댓값 | 최소 유사도 결정에 사용 |
| 변형 질문 최저 정답 유사도 | 변형 질문과 그 원본 사이 유사도의 최솟값 | 〃 |

**최소 유사도(`app.search.min-similarity`) 정하는 방법**: "관계없는 질문 최고 유사도"보다 높고 "변형 질문 최저 정답 유사도"보다 낮은 값으로 정합니다. 두 값이 겹치면(관계없는 질문이 더 높으면) 최소 유사도 필터를 쓰지 않고 0으로 둡니다.

### 3-3. 실행

```sh
GEMINI_API_KEY=... SEARCH_EVAL_FILE=/path/to/questions.json \
  ./gradlew test --rerun --tests '*SearchEvaluationTest'
```

- S3 Vectors 없이 메모리에서 cosine으로 순위를 매깁니다. 임베딩 모델의 품질만 봅니다.
- 결과는 콘솔과 `build/reports/search-eval.md`에 남습니다.
- 질문 39개면 Gemini를 39번 호출합니다. 429가 나면 잠시 기다렸다가 최대 3번 다시 시도합니다.

## 4. 호출 제한

### 4-1. Gemini API 한도

- 한도는 API Key가 아니라 **Google Cloud 프로젝트 단위**로, 분당 요청 수·분당 토큰 수·일일 요청 수가 걸립니다. 일일 한도는 태평양 시간 자정에 초기화됩니다.
- ⚠️ 고정된 공개 표가 없어 **Google AI Studio에서 우리 프로젝트의 실제 값을 확인**해야 합니다. 키를 받을 때 ② 김서영님께 등급(무료/유료)과 한도를 같이 받습니다.

### 4-2. 우리 쪽 보호 장치

| 위치 | 장치 | 문서 |
| --- | --- | --- |
| 인덱싱 Lambda | 최대 동시 실행 2, 429는 SQS 재전달로 뒤로 미룸 | indexing.md 6-2 |
| 백필 | 같은 큐를 거쳐 위 동시 실행 제한을 그대로 받음 | indexing.md 8 |
| 검색 API | 429면 `RATE_LIMITED` 응답, SDK 재시도 없음 | search-api.md 6 |
| 검색 API | ⚠️ 사용자별 분당 검색 횟수 제한 (예: 분당 20회). 한도 확인 후 결정 | ② |
| 평가 실행 | 429면 대기 후 최대 3회 재시도 | 3-3 |

한 사용자가 MCP 클라이언트로 검색을 연달아 호출하면 프로젝트 전체 한도를 다 쓸 수 있으므로, 실제 한도가 낮으면 사용자별 제한을 먼저 넣습니다.

가정: 팀 7명이 QA 총 1,000건 저장, 검색 월 3,000회, 질문 평균 100토큰.

| 항목 | 단가 ⚠️ | 월 사용량 | 월 비용 |
| --- | --- | --- | --- |
| Gemini 임베딩 (유료 등급) | 텍스트 입력 100만 토큰당 $0.20 | 저장 10만 + 검색 30만 토큰 | 약 $0.08 |
| Gemini 임베딩 (무료 등급) | 한도 안에서 무료 | 〃 | $0 |
| S3 Vectors 저장 | GB-월당 약 $0.066 | 벡터 약 4KB × 1,000건 = 4MB | $0.01 미만 |
| S3 Vectors 업로드 | GB당 약 $0.219, 요청당 최소 128KB로 계산 | 1,000건 × 128KB = 128MB | 약 $0.03 |
| S3 Vectors 검색 | 1,000회당 약 $0.0027 + 처리 데이터 | 3,000회 | 약 $0.01 |
| SQS·Lambda | 프리 티어 범위 | | $0 |
| **NAT Gateway** | **시간당 약 $0.059 + GB당 처리 요금** | **24시간 × 30일** | **약 $43** |

- **임베딩과 S3 Vectors 비용은 사실상 0에 가깝습니다.** 평가를 여러 번 돌려도 센트 단위입니다.
- **NAT Gateway가 가장 큰 비용입니다.** 크레딧(약 $120)과 예산 알림(`monthly-10usd`)을 생각하면 그대로 두기 어렵습니다. ⑦ 안정현님과 아래 중 하나를 정해야 합니다.
  - ECS를 퍼블릭 서브넷 + 퍼블릭 IP로 두고 보안 그룹으로 ALB에서 오는 트래픽만 허용 (NAT 불필요)
  - 인덱싱 Lambda는 VPC에 붙이지 않음 (DynamoDB·SQS·S3 Vectors·Gemini 모두 퍼블릭 엔드포인트로 접근 가능)
  - 꼭 프라이빗 서브넷이면 NAT Gateway를 시연·테스트 기간에만 켜기
- S3 Vectors 인터페이스 엔드포인트도 시간당 요금이 붙으므로, 위처럼 퍼블릭 경로를 쓰면 필요 없습니다.
- 단가 출처: [Gemini Embedding 2 가격 (tokencost.app)](https://tokencost.app/blog/gemini-embedding-2-pricing), [S3 Vectors 가격 (AWS)](https://aws.amazon.com/s3/pricing/). Gemini 단가는 제3자 정리 자료라서 ⚠️ Google 공식 가격표에서 다시 확인합니다. NAT Gateway 단가는 서울 리전 기준으로 AWS VPC 가격표에서 확인합니다.

## 6. 개인정보

- **Gemini 무료 등급은 입력 내용을 Google 제품 개선에 쓸 수 있고, 유료 등급은 쓰지 않습니다.** 사용자의 학습 질문이 외부로 나가므로, 실제 사용자 데이터를 넣기 전에 유료 등급으로 바꾸거나 서비스 안내에 명시해야 합니다. ⚠️ 팀 결정 필요 (②)
- 임베딩에는 질문만 보내고 답변은 보내지 않습니다.
- API Key는 Secrets Manager → ECS 태스크 환경변수로만 전달하고 로그·오류 메시지에 남기지 않습니다.
